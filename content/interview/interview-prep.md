### 287 Questions & Answers, in 7 parts, increasing in difficulty

**How to use this:** Go through each part top to bottom, then move to the next, questions get harder as you go. Each part numbers its own questions from 1, so "Q9" means question 9 of whichever part you're in, not a running count across all 287. Don't just read the answers; say them out loud or write them on a whiteboard. For the system design sections, practice drawing the diagram before checking the answer, several are rendered as Mermaid diagrams.

#### Parts

- **[Part 1 — Go Language](/interview-prep-language/)** — Q1–89. Fundamentals, types & generics, concurrency, memory/GC, error handling, performance, testing, web & networking, and common pitfalls & gotchas.
- **[Part 2 — Coding Patterns](/interview-prep-coding-patterns/)** — Q1–23. The 23 recurring patterns behind most coding-interview questions: sliding window, two pointers, tree BFS/DFS, backtracking, topological sort, grid BFS, knapsack, tries, and more.
- **[Part 3 — Databases & SQL](/interview-prep-databases-sql/)** — Q1–32. Database optimization, window functions, CTEs, join algorithms, partitioning, JSON querying, storage/concurrency internals, and zero-downtime schema migrations.
- **[Part 4 — System Design & Distributed Systems](/interview-prep-system-design/)** — Q1–40. System design fundamentals, SQL vs. NoSQL, distributed systems concepts, and system design case studies.
- **[Part 5 — Kafka & Microservices](/interview-prep-kafka-microservices/)** — Q1–41. Kafka in depth for Go, microservices architecture, DDD, CQRS, event sourcing, and event-driven patterns.
- **[Part 6 — Security & Cloud](/interview-prep-security-cloud/)** — Q1–26. Security fundamentals, cloud & infrastructure.
- **[Part 7 — AI Engineering](/interview-prep-ai-engineering/)** — Q1–36. LLM fundamentals, prompting and context engineering, RAG and retrieval systems, and agentic production AI: tool use, MCP, evaluation, and guardrails.
