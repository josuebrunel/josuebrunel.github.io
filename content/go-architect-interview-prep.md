### 207 Questions & Answers, in 5 parts, increasing in difficulty

**How to use this:** Go through each part top to bottom, then move to the next, questions get harder as you go. Don't just read the answers; say them out loud or write them on a whiteboard. For the system design sections, practice drawing the diagram before checking the answer, several are rendered as Mermaid diagrams.

#### Parts

- **[Part 1 — Go Language](/go-interview-prep-language/)** — Q1–75. Fundamentals, types & generics, concurrency, memory/GC, error handling, performance, testing, web & networking.
- **[Part 2 — Databases & System Design](/go-interview-prep-databases-systems/)** — Q76–123. Database optimization, system design fundamentals, distributed systems, and system design case studies.
- **[Part 3 — Kafka & Microservices](/go-interview-prep-kafka-microservices/)** — Q124–162. Kafka in depth for Go, microservices architecture, DDD and event-driven patterns.
- **[Part 4 — Security & Cloud](/go-interview-prep-security-cloud/)** — Q163–187. Security fundamentals, cloud & infrastructure.
- **[Part 5 — Advanced SQL](/go-interview-prep-sql-advanced/)** — Q188–207. Window functions, CTEs, join algorithms, partitioning, JSON querying, and storage/concurrency internals.
